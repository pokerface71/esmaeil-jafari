# Portfolio Design System

This design system follows **Atomic Design** (Brad Frost) with a Tailwind v4 token pipeline.

## Layers

| Layer | Path | Contains |
|---|---|---|
| **Tokens** | `styles/tokens.css` | Raw CSS custom properties: semantic colors (HSL), gradients, glass surfaces, radii. `[data-theme='light']` overrides everything. |
| **Utilities** | `styles/utilities.css` | Shared visual primitives (`.glass-card`, `.spot-card`, `.code-chip`, `.btn-primary`, `.skill-tag`, effect keyframes). |
| **Atoms** | `components/design-system/atoms` | Smallest testable units: Button, Badge, IconBox, CodeChip, GlassCard, SkillTag, GradientText, Card. |
| **Molecules** | `components/design-system/molecules` | Atom compositions: SkillCard, SectionHeader, StatCard, SocialIconLink, ContactInfoItem, ThemeToggle, LanguageSwitcher. |
| **Organisms** | `components/design-system/organisms` | Self-sufficient sections: Header, Footer, TechMarquee, AuroraBackground, BlogSection, CodeBlock, MarkdownRenderer, effects. |
| **Templates** | `components/design-system/templates` | Page-level composition (HomeTemplate) plus behavior hooks (reveal, spotlight, parallax, tilt). |
| **Pages** | `pages/` | Thin wrappers: SEO/head concerns only. |

## Rules

1. **No hardcoded colors.** Everything consumes `hsl(var(--token))` or a Tailwind token mapped in `@theme` (globals.css).
2. **Downward imports only.** Atoms never import molecules/organisms. Templates compose everything.
3. **Behavior lives in hooks** (`components/design-system/hooks`) so it can be tested headlessly.
4. **Every atom & molecule ships a story** with `autodocs`; RTL + theme switching come from the Storybook toolbar globals.
5. **Unit tests colocated under `tests/`** mirror the design-system structure.
